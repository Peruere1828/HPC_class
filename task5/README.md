构造新的数据类型 `diag_type`，发送矩阵对角线。

$(i,i)$ 的偏移量是 $i \times N + i$，只有一个元素，因此构造数据类型：

```c
for (int i = 0; i < N; i++) {
    len[i] = 1;
    disp[i] = i * N + i;
}
MPI_Type_indexed(N, len, disp, MPI_INT, &diag_type);
```

运行：

```
make
mpirun -n 1 ./main
```
