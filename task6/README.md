改用Gauss Siedel红黑排序迭代实现求解。

每个进程的块的内点 $(i,j)$ 对应的全局坐标是 $(x_0+i,y_0+j)$，依据全局坐标的奇偶性给点染色。先红点原地更新，然后更新边界数据，再黑点原地更新，更新边界数据。

itmax改到80000让它收敛。

运行：

```
make
mpirun -np 16 ./main
```

输出：

原始实现：

```
Total iteration=31246, residual=9.9951e-07, Time=9.0552e-01
||u-ut|| = 7.2856e-03
```

GS实现：

```
Total iteration=16793, residual=9.9966e-07, Time=6.3803e-01
||u-ut|| = 7.2856e-03
```

可以看到GS的收敛速度更快，使得它虽然多一倍通信，仍然比Jacobi实现快1.4倍左右。
